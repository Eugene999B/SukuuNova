# Learning quality: primary mathematics follow-up

The user reported repetitive tasks and questions beyond the selected class. Review found shared primary templates serving percentages, area formulas and multi-step rules in lower-primary selections; random-seed exposure identities; ambiguous repeated-digit place-value prompts; possible tied modes despite a single accepted answer; and an unsupported 80-million capacity constant.

## Changes
- Dedicated Basic 1–3 tasks for number, operations, equal grouping/sharing, fractions, patterns, shapes/position, measurement and table reading.
- Bounded arithmetic consistent with the currently mapped 100/1,000/10,000 ranges, simple language, task-based difficulty and evidence tables.
- Session filtering prevents generic generators from adding older-level maths back into these classes.
- Stable identities use mathematical parameters and answers, ignoring seed and choice order. Mixed topics cycle through every task family independently.
- Explicit place-value position, distinct fractions in comparisons, unique statistical modes, nonnegative distinct answer choices, and no percentages in Basic 4 fractions/decimals.
- Capacity represents conservative task-family counts, not millions of authored questions.
- Nursing foundation recall stays difficulty 1; moving between course years does not inflate it.

## Curriculum evidence and limits
NaCCA's [2019 primary curriculum index](https://nacca.gov.gh/learning-areas-subjects/new-standards-based-curriculum-2019/) identifies separate lower and upper primary mathematics documents. Direct downloads of the lower/upper PDF timed out during this pass. Therefore this is a conservative correction against the existing class map and task complexity, not a completed indicator-by-indicator NaCCA certification. Ghanaian teachers should review exact term placement and missing content.

Remaining: broad subject-by-subject and exam-level review, deeper original higher-level tasks, lower-primary visual/fraction coverage, clinical educator review, native-language review, and removal of remaining unsupported capacity claims in other generators. Successful software tests do not establish curriculum completeness.
